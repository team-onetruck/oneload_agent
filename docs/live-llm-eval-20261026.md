## 2. 근거 · 출처 41문항 (R6 `retrieval_holdout_v2` 40문항 + 택시 기본요금 1문항)

검색: R3 `hangil_rag` 공식 문서 검색 (v0.3.0). 채점: 범위 밖 질문은 출처 · 금액 · 시간 숫자가 없으면 통과, 정상 질문은 R6 정답 문서(gold)가 출처에 있으면 통과. 무관한 출처 = gold 밖 출처 수의 합.

| | main `a732577` (수정 전) | PR #11 + v4 (2회) | PR #11 + v5 |
|---|---|---|---|
| 범위 밖 거르기 | 21/21 | 21/21 · 21/21 | 21/21 |
| 정상 질문 | 19/20 | 19/20 · 17/20 | 18/20 |
| **무관한 출처 합계** | **29** | 3 · 4 | **0** |

- PR #11(이슈 #5)의 효과는 **무관한 출처 29 → 0** 이다. main은 정상 질문 대부분에 출처가 2~3개씩 붙었다 (예: H2-15 환승 질문에 기후동행카드 · 외국인 교통카드 문서).
- 범위 밖 거르기는 main에서도 21/21: 실제 LLM에서는 기존 관련성 검사(verify)가 범위 밖 응답을 막았다.
- 정상 질문은 같은 조건(v4) 2회에 19 → 17로 흔들려, v5의 18은 편차 범위 안이다.
- H2-20(영어, 열차 비교)은 모든 실행에서 인용 번호를 빠뜨려 cannot_answer.
- v2는 이미 공개된 평가셋이라 새 독립 평가가 아니다 (R6 기준). 회귀 확인용이다.
